# Analyst workspace — bounded ML experiments (AW-9)

Additive to preparation AW-8. Model training is a local analyst experiment, never an identity, SQL authorization, production forecast or automated decision mechanism.

1. POST `/workbench/ml` authenticates analyst, CSRF, common admission/cancel/time/output limits. CSV uses AW-8 parser, ≤3,000 rows, ≤30 selected features, ≥100 observations. Explicit target, feature allowlist, task, decision context and confirmation of feature availability are mandatory. No automatic target choice or model/provider call. No pickle/code uploads or arbitrary estimator parameters.
2. Frozen source hash and reproducible seed47 split precede any learned preprocessing. Strategy: random stratified classification/iid regression; group-disjoint holdout and GroupKFold; chronological unique-date holdout and forward unique-date folds. Split key is excluded from features. Time and group strategies are alternatives, not a guarantee of simultaneous constraints. Same feature vector across partitions is refused to prevent exact duplicate leakage; target-copy features are refused. These checks cannot detect every semantic/future/proxy leak: user must choose as-of features, label horizon and observation grain appropriately.
3. Candidate selection uses only training 3-fold CV. Train-only schema, imputation, signed-log skew transformation, MinMax scaling, category encoding are inside every estimator pipeline. Dummy baseline, bounded Random Forest and linear baseline are compared. Optional numeric-only SMOTE is inside each training fold; never resamples validation/holdout. Inapplicable SMOTE is refused, never silently applied to one-hot categorical values. No test-guided rounding/tuning. OOF stacking remains a separate experiment until group/time safe evaluation is built.
4. Final selected estimator is fit on development data, evaluated once on untouched20% holdout. Report CV mean/std, holdout baseline and selected metrics, confusion/per-class recall or regression errors, class/support counts, warnings, split row indices + digest, train schema/source/code/dependency fingerprints and fixed budget. Undefined scores are null with no fabricated values. No global accuracy promise. Repeated user experiments reuse the deterministic split and are clearly exploratory; holdout reuse can bias human selection.
5. Adapt Influencer notebook b217890 cell63 preprocessing/log transforms with fit/transform corrected; cell66 log-MSE function with finite/nonnegative guard and RMSLE in original target domain. Source/function/target changes/test evidence in reuse ledger. SNIPS/LSTM is deferred until measured benefit vs baseline.
6. Store owner-scoped experiment card/recipe in Postgres; no raw CSV, row values or fitted executable model persisted. Receipts export JSON. Retrievable card via owner-only endpoint; cross-owner404. Audit contains identity/run id only. No serving/deployment claim.
7. UI: an advanced model studio reached via Find action and analysis page; explicit columns/task/split/context; interpretable baseline comparison, real counts and limitations. Real open-data fixture from sklearn wine/diabetes datasets attributed and checksummed; classification/regression values are actual run results. Browser desktop/mobile QA and auth/ownership tests gate closure.

References: https://scikit-learn.org/stable/common_pitfalls.html ; https://scikit-learn.org/stable/modules/cross_validation.html ; https://imbalanced-learn.org/stable/common_pitfalls.html . Local package acceptance does not close credit/tenant/pilot/large-scale gates.
